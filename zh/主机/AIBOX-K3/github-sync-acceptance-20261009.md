# GitHub 增删改同步联调

本文仅用于 2026 年 10 月 9 日链路验收，不属于 AIBOX-K3 产品操作说明。验收结束后删除。

版本标记：GITHUB-SYNC-V1-20261009。

验收场景：将 GitHub 文档提交拉取到社区并发布，等待自动知识库同步，再验证测试wiki目录中的正文和向量。只有目标回执为 completed，才认定本阶段入库完成。

## 第一版校验段落 1

本段属于临时同步验收数据。首先核对 GitHub 提交与社区发布记录中的提交编号一致，然后核对运行时发布确认。新增文档必须出现在目标目录，正文保留本轮版本标记；更新后旧正文应被替换，旧文件和旧向量应清理；删除后目标文档关系、文件和向量均应消失。社区既有正文解析问题仍单独计为警告，不代表本测试页面失败。此段用于验证长正文分块在后续缩短文档时能被完整清理。
